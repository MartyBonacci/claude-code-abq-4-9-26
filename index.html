Since Our Last Meetup (Mar 12)

  • Computer Use — Claude can click, scroll & navigate your screen (Pro / Max)
  • Auto Mode — smart approval layer; 93% of prompts already auto-approved (Team / Enterprise / API)
  • Scheduled Tasks — recurring Claude Code jobs in the cloud, laptop off or on
  • Cloud Auto-Fix — Claude follows your PRs, fixes CI, addresses review comments
  • Dispatch — assign tasks from your phone, return to finished work on desktop
  • /powerup — learn Claude Code features with in-terminal animated lessons
  • 1M context GA — Opus 4.6 + Sonnet 4.6, native 1M tokens at standard pricing
Rapid fire — 15-20 seconds per item. Computer Use dropped March 23 — Claude can literally use your computer, click buttons, navigate apps. Research preview, Pro and Max. Auto Mode is the smart permissions layer — users were already approving 93% of prompts, so those are now automatic with a safety classifier. Team, Enterprise, and API only for now. Scheduled Tasks let you set up recurring Claude Code jobs that run in the cloud — your laptop can be off. Cloud Auto-Fix watches your PRs, fixes CI failures and review comments, pushes fixes. Dispatch lets you assign tasks from your phone to Claude running on your desktop — walk away, come back to finished work. /powerup is great for newcomers — animated interactive lessons right in your terminal. And 1M context is now GA at standard pricing on Opus and Sonnet 4.6, no beta header needed.
